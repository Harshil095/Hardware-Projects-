# Scientific Calculator

A scientific calculator built using an Arduino UNO, 16x2 LCD display, and a 4x6 push-button matrix keypad.  
The project is programmed in AVRGCC and supports both basic and advanced mathematical operations.

## Features
- Basic arithmetic operations (+, -, ×, ÷)
- Trigonometric and inverse trigonometric functions
- Exponential function (e^x)
- Quadratic equation solver
- Polynomial differentiation
- 2x2 matrix addition and multiplication

## What I learnt 
- Embedded C
- AVR-GCC
- Arduino Hardware

## Overview
The calculator uses a 4x6 keypad matrix to reduce I/O pin usage and a 16x2 LCD for displaying expressions and results. The system performs realtime calculations and supports advanced mathematical operations directly on hardware.
